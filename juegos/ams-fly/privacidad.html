AMS FLY · PRIVACIDAD

Política de privacidad

Última actualización: 2 de octubre de 2026.

1. Responsable

El tratamiento asociado a AMS Fly es gestionado por Avila Mora Soluciones. Para consultas relacionadas con privacidad, el usuario puede comunicarse mediante los canales de contacto publicados en el sitio oficial de Avila Mora Soluciones.

2. Datos que recopilamos

  • Nombre o alias del piloto.
  • País seleccionado.
  • Número de teléfono proporcionado para identificar al piloto.
  • Puntuaciones, mensajes del ranking y fechas asociadas a las partidas publicadas.
  • Datos técnicos mínimos necesarios para operar el sitio y prevenir abuso, cuando estén disponibles.

3. Finalidades

Los datos se utilizan para identificar participantes, mantener el ranking, administrar el evento, verificar resultados, prevenir abuso, gestionar el premio y atender consultas relacionadas con la participación.

4. Visibilidad

El ranking público muestra el nombre o alias, país, ave, puntuación y mensaje publicado. El número de teléfono no se muestra públicamente y queda reservado para la gestión privada del participante.

5. Proveedores

Los datos del juego se almacenan en la infraestructura de base de datos utilizada por AMS Fly. Si se habilita la verificación mediante SMS, se podrá utilizar un proveedor especializado de verificación de mensajes para enviar y validar el código.

6. Conservación

Los datos se conservarán durante el tiempo necesario para administrar el evento, verificar resultados, atender reclamaciones y cumplir obligaciones legales aplicables. Los datos que ya no sean necesarios podrán eliminarse o anonimizarse conforme corresponda.

7. Derechos

El titular puede solicitar información sobre sus datos, actualización, corrección, supresión cuando proceda y demás derechos reconocidos por la normativa colombiana aplicable, mediante los canales de contacto de Avila Mora Soluciones.

8. Seguridad

Se aplican controles técnicos para restringir el acceso a datos privados, separar la administración del ranking público y reducir el riesgo de manipulación. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

9. Cambios

Esta política puede actualizarse cuando cambie la mecánica, la infraestructura o los requisitos legales del evento. La versión vigente será publicada en esta página.
