# Documentos comerciales AMS

## Propósito

Gestión → Documentos sirve para preparar PDFs claros y profesionales que acompañen el trabajo con cada cliente.

## Documentos disponibles

1. **Propuesta comercial / cotización** — alcance, entregables, tiempos, conceptos, valores, vigencia y condiciones.
2. **Acta de entrega** — lo entregado, pendientes, observaciones, correcciones y aceptación.
3. **Comprobante de pago** — fecha, valor, método, referencia, período y concepto.
4. **Ficha de cliente / proyecto** — registro interno para consultar y reutilizar información.

## Regla de uso

Cada documento se genera para un cliente y un caso concreto. No se debe entregar una plantilla sin revisar.

Antes de compartir un PDF:
- revisar nombre del cliente;
- revisar servicio y alcance;
- revisar fechas;
- revisar valores y moneda;
- revisar entregables;
- revisar datos de contacto;
- revisar que no existan datos de otra persona o proyecto.

## Propuestas

La propuesta debe dejar claros:
- qué se va a construir o entregar;
- qué está incluido;
- qué no está incluido;
- tiempos estimados;
- valor y forma de pago;
- mantenimiento o mensualidad, cuando exista;
- condiciones relevantes del caso.

## Actas

El acta sirve para dejar constancia de la entrega y de la revisión del proyecto. Debe reflejar lo que realmente se entregó y las observaciones que existan.

## Comprobantes de pago

El comprobante interno registra un pago recibido y no debe presentar datos o características que no correspondan al medio de pago utilizado.

## Archivo

Conservar:
- briefing;
- propuesta aceptada;
- evidencias de aceptación;
- comprobantes de pago;
- actas;
- PDFs finales;
- comunicaciones relevantes;
- entregables importantes.

## Generador documental

Ruta:

`/gestion/documentos/`

El generador reutiliza el cliente maestro de Gestión y las plantillas de servicio. Los borradores se guardan localmente en el dispositivo actual.

## Evolución

Si AMS más adelante necesita otro tipo de documento, se añade solamente cuando exista una necesidad real y concreta.
